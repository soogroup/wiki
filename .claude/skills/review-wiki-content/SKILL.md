# Wiki 컨텐츠 검증 스킬

## 개요

Wiki 항목들이 원본 회의록과 일치하는지 검증합니다.

**Input**: 회의록 파일 + Wiki 항목들 (결정/액션/보류/기각)  
**Output**: 5가지 검증 결과 + 개선 권고사항

---

## 5가지 검증 항목

### 1️⃣ 일치성 (Consistency)

**확인 사항**:
- Wiki 항목의 내용이 회의록과 일치하는가?
- 결정 사유, 액션 마감, 상태 등이 정확한가?
- 날짜, 이름, 숫자가 회의록과 동일한가?

**예시 - 문제**:
```
회의록: "A사 선정, 수수료 2.2%"
Wiki: "A사 선정, 수수료 2.5%"  ❌ (숫자 불일치)
```

**예시 - 정상**:
```
회의록: "A사 선정, 수수료 2.2%"
Wiki: "A사 최종 선정 (수수료 2.2%)"  ✅ (표현은 다르지만 내용 일치)
```

---

### 2️⃣ 할루시네이션 (Hallucination Detection)

**확인 사항**:
- Wiki에만 있는 내용이 없는가?
- 회의록에 적혀있지 않은데 추가된 것은?
- 추론된 내용이 아닌가? (예: 미명시된 담당자 추정)

**예시 - 문제**:
```
회의록: "A사 선정" (사유 명시 안 함)
Wiki: "A사 선정 이유: 1) 저렴함 2) 신속함 3) 기술 지원 우수"
     ❌ (회의록에 없는 이유들 추가)
```

**예시 - 정상**:
```
회의록: "박준서가 A사와 연동 스펙 협의 진행 중"
Wiki: "담당자: 박준서"  ✅ (회의록에서 명시된 정보)
```

---

### 3️⃣ 누락 (Omission)

**확인 사항**:
- 회의록의 중요 내용이 Wiki에 빠졌는가?
- 결정의 배경 설명이 없는가?
- 액션의 완료 기준이 누락되었는가?
- 조건이나 제약사항이 없는가?

**예시 - 문제**:
```
회의록:
"A사 선정. 다만 우려사항: 연동 문서 부실.
따라서 스펙 협의 기간 필요. 박준서가 담당."

Wiki:
"A사 선정" (우려사항, 필요 조건 모두 누락)  ❌
```

**예시 - 정상**:
```
회의록의 모든 조건, 배경, 이유가 Wiki에 포함됨  ✅
```

---

### 4️⃣ 액션 추적 (Action Lifecycle)

**확인 사항**:
- 액션 항목의 상태가 정확한가? (pending/in_progress/completed/blocked)
- "열림" 상태인가? (미완료 액션이 pending/in_progress로 표시)
- "홀드" 상태인가? (blocked로 표시, 사유 명시)
- "조용히 사라짐"은 없는가? (완료 안 된 액션이 갑자기 없어짐)

**예시 - 문제 1 (상태 오류)**:
```
회의록: "박준서가 스펙 협의 중, 마감 6월 18일"
Wiki: "상태: completed" ❌ (아직 진행 중인데 완료로 표시)
```

**예시 - 문제 2 (사라짐)**:
```
이전 회의: "박준서 - A사 스펙 협의, 마감 6월 18일"
현재 회의: (아무 기록도 없음) ❌ (액션이 조용히 사라짐)
→ 해결책: pending/completed/obsolete로 명시 필수
```

**예시 - 정상**:
```
action-2026-06-11-박준서-a사-스펙-협의.md
상태: in_progress
블로킹_원인: A사 담당자 응답 대기  ✅
```

---

### 5️⃣ 참조 정확성 (Reference Integrity)

**확인 사항**:
- Cross-reference ([[파일명.md]])가 정확한가?
- 의존_결정이 실제로 존재하는가?
- 참조되는 파일들이 정확하게 연결되어 있는가?
- 끊긴 참조(Broken Reference)는 없는가?

**예시 - 문제 1 (파일명 오류)**:
```
Wiki: "의존_결정: [[pg사-선정.md]]"
실제 파일: "결제-2026-06-11-pg사-a사-최종-선정.md"
❌ (파일명이 다름, 참조 끊김)
```

**예시 - 문제 2 (논리적 오류)**:
```
Action: "A사 스펙 협의"
의존_결정: "온보딩 개선 Q3 연기"  ❌ (논리적 관계 없음)
```

**예시 - 정상**:
```
Action: "A사 스펙 협의"
의존_결정: "결제-2026-06-11-pg사-a사-최종-선정.md"  ✅ (논리적)
```

## 검증 프로세스

### Step 1: 회의록과 Wiki 파일 읽기

사용자가 제공:
- 회의록 파일 (raw-sources/회의록/YYYY-MM-DD-주제.md)
- 해당 회의의 Wiki 항목들 (decisions/, pending/, action_items/, rejected/)

---

### Step 2: 각 Wiki 항목별 5가지 검증

**각 항목마다**:
1. **일치성**: 내용이 회의록과 일치하는가?
2. **할루시네이션**: 없는 내용이 추가되었는가?
3. **누락**: 중요 내용이 빠졌는가?
4. **액션 추적**: 상태가 정확한가? (lifecycle tracking)
5. **참조 정확성**: 링크가 올바른가?

**발견 결과**:
- ✅ PASS: 모든 검증 통과
- ⚠️ WARNING: 경미한 문제 (표현 차이, 미확인 가능한 부분)
- ❌ FAIL: 심각한 문제 (내용 불일치, 누락, 할루시네이션)

---

### Step 3: 개선 권고

**검증 결과에 따라**:
- PASS → "그대로 유지"
- WARNING → "확인 및 조정 필요"
- FAIL → "수정 필수"

**구체적 권고**:
```
❌ FAIL - 일치성
문제: Wiki의 수수료가 2.5%인데 회의록은 2.2%
권고: Wiki 파일 수정: "수수료 2.2%" 로 변경

⚠️ WARNING - 누락
문제: 결정의 사유가 회의록에는 상세하지만 Wiki는 간단함
권고: Wiki에 "수수료 절감 우선" 배경 추가

✅ PASS - 액션 추적
상태가 정확하고 블로킹 사유도 명시됨
```

## 사용 방법

### 프롬프트 예시

```
2026-06-11 회의록을 검증해줄래.
경로: raw-sources/회의록/2026-06-11-제품주간회의.md

Wiki 파일들:
- wiki/decisions/결제-2026-06-11-pg사-a사-최종-선정.md
- wiki/decisions/결제-2026-06-11-결제-연동-완료-일정-변경.md
- wiki/action_items/action-2026-06-11-박준서-a사-스펙-문서-확보.md
- wiki/pending/온보딩-2026-06-11-온보딩-개선-q3-연기.md

5가지 검증(일치성/할루시네이션/누락/액션추적/참조)을 해줄래.
```

---

### 검증 결과 포맷

```markdown
# 2026-06-11 제품주간회의 검증 결과

## 파일 1: 결제-2026-06-11-pg사-a사-최종-선정.md

### 1. 일치성: ✅ PASS
- A사 선정 ✓
- 수수료 2.2% ✓
- 신청사 부실 우려 ✓

### 2. 할루시네이션: ✅ PASS
- 회의록에 없는 추가 정보 없음

### 3. 누락: ⚠️ WARNING
- 결정 사유가 간단함 (수수료 절감만 명시)
- 권고: "B사/C사와의 비교 표" 추가

### 4. 액션 추적: ✅ PASS
- (Decision 항목이므로 N/A)

### 5. 참조 정확성: ✅ PASS
- [[action-2026-06-11-박준서-a사-스펙-문서-확보.md]] 존재 ✓
- [[결제-2026-06-11-결제-연동-완료-일정-변경.md]] 존재 ✓

---

## 파일 2: action-2026-06-11-박준서-a사-스펙-문서-확보.md

### 1. 일치성: ✅ PASS
- 담당자: 박준서 ✓
- 마감: 2026-06-18 ✓

### 2. 할루시네이션: ✅ PASS

### 3. 누락: ⚠️ WARNING
- 완료 기준이 회의록에 명시되지 않음 (Wiki에 추가함)
- 권고: "이것은 추론된 정보" 로 표시 또는 제거

### 4. 액션 추적: ✅ PASS
- 상태: pending (미시작) ✓
- 아직 홀드/블로킹 상태 아님 ✓

### 5. 참조 정확성: ✅ PASS
- 의존_결정이 존재 ✓

---

## 종합 평가

- 총 5개 항목: 3 PASS, 2 WARNING, 0 FAIL
- 즉시 수정 필요: 없음
- 권고사항: 2개 (표현 개선)

**권장 조치**: 
1. FAIL 항목이 없으므로 Wiki 배포 가능
2. WARNING 2개는 선택적으로 개선 가능
```

## 핵심 검증 체크리스트

각 Wiki 항목마다:

```
일치성:
[ ] 핵심 내용이 회의록과 일치하는가?
[ ] 숫자, 날짜, 이름이 정확한가?
[ ] 결정 사유가 일치하는가?

할루시네이션:
[ ] 회의록에 없는 정보를 추가하지 않았는가?
[ ] 추론된 내용을 명시했는가?

누락:
[ ] 중요 배경 설명이 있는가?
[ ] 조건/제약사항이 명시되었는가?
[ ] 액션의 완료 기준이 있는가?

액션 추적:
[ ] 상태가 정확한가? (pending/in_progress/completed/blocked)
[ ] 블로킹 사유가 명시되었는가?
[ ] 완료/미완료가 명확한가?

참조 정확성:
[ ] 파일 참조가 존재하는가?
[ ] 참조가 논리적으로 일치하는가?
[ ] 끊긴 참조는 없는가?
```
