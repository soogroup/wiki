# 전환 이벤트 로깅 추가

## 액션 설명

B안 배포 전 **온보딩 단계별 사용자 행동 추적 이벤트** 추가.

현재는 전환 데이터만 있어서, 어디서 사용자가 이탈하는지 추적 불가능.

## 필수 이벤트 4가지

| 이벤트 | 설명 | 트리거 |
|--------|------|--------|
| `step_started` | 각 단계 진입 | 사용자가 단계 1, 2, 3 진입 |
| `field_filled` | 필드 입력 | 각 필드 입력 완료 |
| `step_completed` | 단계 완료 | 단계의 모든 필드 완성 |
| `flow_abandoned` | 이탈 | 단계 중간 이탈 (페이지 이동) |
